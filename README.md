# homebrew-maclean

[Maclean](https://github.com/EathonEvans/maclean) 的 Homebrew Tap —— 极简 macOS 菜单栏工具：显示器休眠 · 清洁模式。

## 安装

```bash
brew tap EathonEvans/maclean
brew install --cask maclean
```

或一步到位：

```bash
brew install EathonEvans/maclean/maclean
```

## 说明

- 安装后自动移除隔离标记，**首次打开无 Gatekeeper 弹窗**
- 清洁模式需在 系统设置 → 隐私与安全性 → 辅助功能 中允许 Maclean
